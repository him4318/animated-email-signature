Where to paste it

Menu names change between app versions, so look for "Signature" in your mail app's settings if these don't match.

Gmail (web)
Settings (gear) → See all settings → General → Signature → Create new → paste. Under "Signature defaults" pick it for new emails and for replies, then Save Changes at the bottom of the page.
Outlook
Settings → Signatures (in older desktop Outlook: File → Options → Mail → Signatures) → new signature → paste → set it as the default → Save.
Apple Mail
Mail → Settings → Signatures → + → paste. Untick "Always match my default message font" so the layout stays.
